## Chess
How to run (terminal): \
Open a terminal in the project directory and type: \
`python terminalChess.py` \
The game will start with white to move. \

How to run (pygame): \
Ensure that pygame is installed. If you don't have it yet, run `pip install pygame` in your terminal. \
Open a terminal in the project directory and type: \
`python pygameChess.py` \
The game will start with white to move. \
